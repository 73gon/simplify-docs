Presets speichern häufig verwendete Filterkombinationen und ermöglichen ein
schnelles Anwenden vordefinierter Ansichten.

## Preset verwenden

<Steps>
  <Step title="Preset-Auswahl öffnen">
    Öffnen Sie die Preset-Auswahl in der Werkzeugleiste.
  </Step>
  <Step title="Preset auswählen">Wählen Sie das gewünschte Preset aus.</Step>
  <Step title="Filter werden angewendet">
    Die gespeicherten Filter werden automatisch angewendet.
  </Step>
</Steps>

## Eigenes Preset speichern

<Steps>
  <Step title="Filter einstellen">Stellen Sie die gewünschten Filter ein.</Step>
  <Step title="Filter speichern">Klicken Sie auf **„Filter speichern"**.</Step>
  <Step title="Namen vergeben">Geben Sie einen Namen für das Preset ein.</Step>
  <Step title="Bestätigen">
    Bestätigen Sie die Eingabe. Das Preset steht ab sofort in der Auswahl zur
    Verfügung.
  </Step>
</Steps>
