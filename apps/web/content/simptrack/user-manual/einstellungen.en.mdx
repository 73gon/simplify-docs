Click the **gear icon** in the toolbar to open the widget settings. There you
can customise filters, columns and templates individually.

## Filters

In the **"Filters"** tab you can show or hide individual filters.

- Click the **eye icon** → show / hide a filter
- Hidden filters no longer appear in the filter area
- Already saved presets continue to work

## Columns

In the **"Columns"** tab you can manage the visible table columns.

- Click the **eye icon** → show / hide a column
- Hidden columns are no longer displayed in the table
- The order reflects the current table view

## Templates

In the **"Templates"** tab you can manage saved filter templates.

| Icon             | Function                      |
| ---------------- | ----------------------------- |
| Drag-&-drop icon | Change the order of templates |
| Eye icon         | Show / hide a template        |
| Trash icon       | Delete a template             |

### Reordering templates

<Steps>
  <Step title="Hold the drag-&-drop icon">
    Press and hold the drag-&-drop icon of the template.
  </Step>
  <Step title="Move the template">
    Drag the template to the desired position.
  </Step>
  <Step title="Release">
    Release the mouse button. The new order is **saved automatically**.
  </Step>
</Steps>
