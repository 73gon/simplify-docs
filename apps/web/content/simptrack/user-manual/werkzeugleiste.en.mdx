The toolbar is located above the filters and provides various functions for
customising and managing the view.

## Available functions

| Function         | Description                                                   |
| ---------------- | ------------------------------------------------------------- |
| **Full screen**  | Opens the widget in a larger full-screen view in the browser. |
| **Excel export** | Exports all currently filtered data as an Excel file.         |
| **Dark mode**    | Toggles between light and dark design.                        |
| **Zoom**         | Enlarges or reduces the widget display.                       |
| **Settings**     | Opens the settings for columns, filters and presets.          |

## Using zoom

The widget supports various zoom levels. Using the buttons:

- **Minus (−)** — zoom out
- **Reset** — restore default size
- **Plus (+)** — zoom in

The display can be scaled between **50 % and 200 %**.

## Excel export

Using the **"Excel export"** button you can download all currently filtered data
as an Excel file. The exported file contains:

- only **visible columns**,
- current **formatting**,
- all **matching records**.

## Full-screen mode

Click **"Full screen"**. The widget opens in a larger browser view.

## Dark mode

Click the **dark mode icon** (sun / moon). The display switches between light
and dark mode.
