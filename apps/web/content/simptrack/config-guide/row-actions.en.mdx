slug: row-actions

appliesTo: SimpTrack 1.0
description: Configure per-row action buttons.
---

`ROW_ACTIONS` defines the buttons in the action column of each row. Without this
key, no row actions are shown.

```php
$CONFIG['ROW_ACTIONS'] = [
  ['type' => 'history', 'label' => 'History'],
  ['type' => 'invoice', 'label' => 'Invoice'],
];
```
