Die Werkzeugleiste befindet sich oberhalb der Filter und enthält verschiedene
Funktionen zur Anpassung und Verwaltung der Ansicht.

## Verfügbare Funktionen

| Funktion          | Beschreibung                                                    |
| ----------------- | --------------------------------------------------------------- |
| **Vollbild**      | Öffnet das Widget in einer größeren Vollbildansicht im Browser. |
| **Excel Export**  | Exportiert alle aktuell gefilterten Daten als Excel-Datei.      |
| **Dark Mode**     | Wechselt zwischen hellem und dunklem Design.                    |
| **Zoom**          | Vergrößert oder verkleinert die Darstellung des Widgets.        |
| **Einstellungen** | Öffnet die Einstellungen für Spalten, Filter und Presets.       |

## Zoom verwenden

Das Widget unterstützt verschiedene Zoomstufen. Mit den Schaltflächen:

- **Minus (−)** — Ansicht verkleinern
- **Zurücksetzen** — Standardgröße wiederherstellen
- **Plus (+)** — Ansicht vergrößern

Die Darstellung lässt sich zwischen **50 % und 200 %** skalieren.

## Excel Export

Mit der Schaltfläche **„Excel Export"** können alle aktuell gefilterten Daten als
Excel-Datei heruntergeladen werden. Die exportierte Datei enthält:

- nur **sichtbare Spalten**,
- aktuelle **Formatierungen**,
- alle **passenden Datensätze**.

## Vollbildmodus

Klicken Sie auf **„Vollbild"**. Das Widget öffnet sich in einer größeren
Browseransicht.

## Dark Mode

Klicken Sie auf das **Dark-Mode-Symbol** (Sonne / Mond). Die Darstellung wechselt
zwischen hellem und dunklem Modus.
