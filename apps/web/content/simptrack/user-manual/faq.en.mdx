## My settings have disappeared

Personal settings are stored in the browser. If you clear the browser cache or
use a different device, you start with the default settings.

## A column is missing

Which columns are shown is defined by the configuration. If an expected column is
permanently missing, contact your administrator.

## A button does not work

Check whether you have the required permission. Some actions are only available
for certain processes or roles.

## The table is empty

Your active filters may be filtering out every process. Reset the filters (see
[Using filters](/simptrack/user-manual/filter)).

<Callout type="info">
  If a problem can't be solved this way, contact simplify-services support with
  a short description and — if possible — a screenshot.
</Callout>
