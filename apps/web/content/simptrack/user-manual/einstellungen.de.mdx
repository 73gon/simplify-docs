Über das **Zahnrad-Symbol** in der Werkzeugleiste öffnen Sie die Einstellungen
des Widgets. Dort können Filter, Spalten und Vorlagen individuell angepasst
werden.

## Filter

Im Tab **„Filter"** können sichtbare Filter ein- oder ausgeblendet werden.

- Klick auf das **Auge-Icon** → Filter ein- / ausblenden
- Ausgeblendete Filter erscheinen nicht mehr im Filterbereich
- Bereits gespeicherte Presets funktionieren weiterhin

## Spalten

Im Tab **„Spalten"** können sichtbare Tabellenspalten verwaltet werden.

- Klick auf das **Auge-Icon** → Spalte ein- / ausblenden
- Ausgeblendete Spalten werden nicht mehr in der Tabelle angezeigt
- Die Reihenfolge entspricht der aktuellen Tabellenansicht

## Vorlagen

Im Tab **„Vorlagen"** können gespeicherte Filtervorlagen verwaltet werden.

| Symbol           | Funktion                        |
| ---------------- | ------------------------------- |
| Drag-&-Drop-Icon | Reihenfolge der Vorlagen ändern |
| Auge-Icon        | Vorlage ein- / ausblenden       |
| Papierkorb-Icon  | Vorlage löschen                 |

### Vorlagen neu anordnen

<Steps>
  <Step title="Drag-&-Drop-Icon halten">
    Halten Sie das Drag-&-Drop-Icon der Vorlage gedrückt.
  </Step>
  <Step title="Vorlage verschieben">
    Ziehen Sie die Vorlage an die gewünschte Position.
  </Step>
  <Step title="Loslassen">
    Lassen Sie die Maustaste los. Die neue Reihenfolge wird **automatisch
    gespeichert**.
  </Step>
</Steps>
