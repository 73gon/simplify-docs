`config.php` ist die **einzige Konfigurationsquelle** von SimpTrack. Sie
definiert die Datenquelle, die Spalten, die Filter sowie optionales Branding und
Berechtigungen.

## Minimalkonfiguration

```php
<?php
$CONFIG = [];

// 1. Datenquelle
$CONFIG['DATA_VIEW'] = 'VIEW_TABELLE';

// 2. Verbindung
$CONFIG['BASE_URL']            = 'https://jobrouter.kunde.de';
$CONFIG['TRACKING_PASSPHRASE'] = 'bitte-aendern';

// 3. Spalten + Filter
$CONFIG['FIELD_MAP'] = [
  'BELEGNUMMER' => 'Belegnr.',
  'LIEFERANT'   => 'Lieferant',
  'BETRAG'      => 'Betrag',
  'FAELLIG_AM'  => 'Fällig am',
];
```

Mehr ist für einen ersten Start nicht nötig. Alle weiteren Schlüssel haben
sinnvolle Defaults.
