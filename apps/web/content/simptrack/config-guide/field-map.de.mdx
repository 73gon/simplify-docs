`FIELD_MAP` definiert, **welche Spalten** angezeigt werden und **wie** sie
beschriftet sind. In der einfachsten Form ist es eine Zuordnung von Feldname zu
Anzeigename:

```php
$CONFIG['FIELD_MAP'] = [
  'BELEGNUMMER' => 'Belegnr.',
  'LIEFERANT'   => 'Lieferant',
  'BETRAG'      => 'Betrag',
  'FAELLIG_AM'  => 'Fällig am',
];
```

## Spalte mit Optionen

Statt eines Strings kann der Wert ein Array mit Optionen sein:

```php
$CONFIG['FIELD_MAP'] = [
  'BETRAG' => [
    'label'  => 'Betrag',
    'align'  => 'right',
    'filter' => 'range',
  ],
];
```

<Callout type="tip">
  Die Reihenfolge der Einträge in `FIELD_MAP` bestimmt die Standard-Reihenfolge
  der Spalten. Anwender können sie danach per Drag-and-drop anpassen.
</Callout>
