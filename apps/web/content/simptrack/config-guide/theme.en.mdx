---

The optional `THEME` key adapts the appearance to the customer's corporate
design. Without `THEME`, SimpTrack uses its default design.

```php
$CONFIG['THEME'] = [
  'primary'   => '#a0ce4e',
  'radius'    => '0.5rem',
  'density'   => 'comfortable',
];
```
