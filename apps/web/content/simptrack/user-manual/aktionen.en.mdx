Each row can contain several action buttons. Which buttons appear depends on the
configuration and your permissions.

| Button      | Function                   |
| ----------- | -------------------------- |
| **History** | Opens the process history  |
| **Invoice** | Opens the invoice document |

<Callout type="note">
  If you don't see a button, you may be missing the relevant permission, or the
  action is not available for that process.
</Callout>

Click a button to open the respective view in a new window or dialog.
