Die Tabellenzeilen werden farblich hervorgehoben, damit Sie kritische Vorgänge
sofort erkennen.

| Farbe                  | Bedeutung                                      |
| ---------------------- | ---------------------------------------------- |
| **Rot**                | Rechnung ist überfällig                        |
| **Gelb**               | Rechnung ist aktiv, aber noch nicht überfällig |
| **Keine Hervorhebung** | Prozess ist abgeschlossen                      |

<Callout type="warning">
  Rot hervorgehobene Zeilen erfordern in der Regel eine zeitnahe Bearbeitung, da
  die Rechnung bereits überfällig ist.
</Callout>

Die genauen Schwellenwerte für „überfällig“ werden bei der Einrichtung
festgelegt. Wenden Sie sich an Ihren Administrator, wenn die Einstufung von Ihren
Erwartungen abweicht.
