---

`ROW_ACTIONS` definiert die Buttons in der Aktionsspalte jeder Zeile. Ohne diesen
Schlüssel werden keine Zeilenaktionen angezeigt.

```php
$CONFIG['ROW_ACTIONS'] = [
  ['type' => 'history', 'label' => 'Verlauf'],
  ['type' => 'invoice', 'label' => 'Rechnung'],
  ['type' => 'log',     'label' => 'Protokoll'],
];
```
