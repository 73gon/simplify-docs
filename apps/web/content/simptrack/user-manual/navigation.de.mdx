## Scrollen

<Steps>
  <Step title="Horizontal scrollen">
    Verwenden Sie das **Mausrad**, um horizontal durch die Tabelle zu scrollen.
  </Step>
  <Step title="Vertikal scrollen">
    Halten Sie die **Shift-Taste** gedrückt und verwenden Sie gleichzeitig das
    Mausrad. Alternativ nutzen Sie die **Scrollbars** an den Rändern.
  </Step>
</Steps>

## Spalten sortieren

1. Klicken Sie auf eine **Spaltenüberschrift**.
2. Die Tabelle wird nach dieser Spalte sortiert.
3. Durch erneutes Klicken wird die Sortierreihenfolge **umgekehrt**.

Ein **Pfeilsymbol** zeigt die aktuelle Sortierung an.

## Spalten verschieben

1. Klicken und halten Sie eine **Spaltenüberschrift**.
2. Ziehen Sie die Spalte an die **gewünschte Position**.
3. Lassen Sie die Maustaste los.

Die neue Reihenfolge wird **automatisch gespeichert**.
