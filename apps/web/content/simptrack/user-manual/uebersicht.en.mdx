## What is SimpTrack?

SimpTrack is a dashboard widget for monitoring and managing invoice and workflow
processes inside JobRouter. The table lets you:

- **filter and sort** invoices,
- **customize** the table view,
- **open** documents and process information,
- and **export** the data to Excel.

Personal settings such as filters, column order or zoom level are **saved
automatically** and restored the next time you open the widget.

## Layout

| Area           | Function                                    |
| -------------- | ------------------------------------------- |
| Header         | Filters, search and actions                 |
| Table          | Processes with status, data and row actions |
| Column headers | Sorting and reordering of columns           |
