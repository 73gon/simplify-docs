`FIELD_MAP` defines **which columns** are shown and **how** they are labelled. In
its simplest form it maps a field name to a display name:

```php
$CONFIG['FIELD_MAP'] = [
  'BELEGNUMMER' => 'Doc no.',
  'LIEFERANT'   => 'Vendor',
  'BETRAG'      => 'Amount',
  'FAELLIG_AM'  => 'Due date',
];
```

## Column with options

Instead of a string, the value can be an array of options:

```php
$CONFIG['FIELD_MAP'] = [
  'BETRAG' => [
    'label'  => 'Amount',
    'align'  => 'right',
    'filter' => 'range',
  ],
];
```

<Callout type="tip">
  The order of entries in `FIELD_MAP` determines the default column order. Users
  can then rearrange them via drag-and-drop.
</Callout>
