Jede Zeile kann verschiedene Aktionsbuttons enthalten. Welche Buttons angezeigt
werden, hängt von der Konfiguration und Ihren Berechtigungen ab.

| Button        | Funktion                     |
| ------------- | ---------------------------- |
| **Verlauf**   | Öffnet die Prozesshistorie   |
| **Rechnung**  | Öffnet das Rechnungsdokument |

<Callout type="note">
  Sehen Sie einen Button nicht, fehlt Ihnen möglicherweise die entsprechende
  Berechtigung oder die Aktion ist für diesen Vorgang nicht verfügbar.
</Callout>

Klicken Sie auf einen Button, um die jeweilige Ansicht in einem neuen Fenster
bzw. Dialog zu öffnen.
