Über den optionalen Schlüssel `THEME` passen Sie das Erscheinungsbild an das
Corporate Design des Kunden an. Ohne `THEME` verwendet SimpTrack sein
Standard-Design.

```php
$CONFIG['THEME'] = [
  'primary'   => '#a0ce4e',
  'radius'    => '0.5rem',
  'density'   => 'comfortable',
];
```
