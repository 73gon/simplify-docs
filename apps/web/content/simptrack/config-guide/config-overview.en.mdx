`config.php` is SimpTrack's **single source of configuration**. It defines the
data source, the columns, the filters as well as optional branding and
permissions.

## Minimal configuration

```php
<?php
$CONFIG = [];

// 1. Data source
$CONFIG['DATA_VIEW'] = 'ER_VORGANG';

// 2. Connection
$CONFIG['BASE_URL']            = 'https://jobrouter.customer.com';
$CONFIG['TRACKING_PASSPHRASE'] = 'please-change';

// 3. Columns + filters
$CONFIG['FIELD_MAP'] = [
  'BELEGNUMMER' => 'Doc no.',
  'LIEFERANT'   => 'Vendor',
  'BETRAG'      => 'Amount',
  'FAELLIG_AM'  => 'Due date',
];
```

That is all you need to get started. Every other key has a sensible default.
